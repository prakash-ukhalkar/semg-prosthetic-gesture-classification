# Project Reference Document

# Project Title

Machine Learning-Based sEMG Prosthetic Gesture Classification Using Publicly Available Datasets

---

# Project Overview

This project aims to develop a complete, reproducible machine learning pipeline for classifying hand and wrist gestures from surface electromyography (sEMG) signals collected using wearable sensors.

The project is intended for academic research and publication in biomechanics, biomedical engineering, rehabilitation engineering, and assistive technology journals.

The entire workflow will be implemented using Python, Jupyter Notebooks, and open-source libraries.

The project follows reproducible research principles.

---

# Primary Objectives

Develop a complete end-to-end machine learning system capable of:

• Loading publicly available sEMG datasets
• Understanding dataset characteristics
• Preprocessing raw EMG signals
• Performing signal filtering
• Segmenting signals using sliding windows
• Extracting biomechanical and statistical features
• Selecting the most informative features
• Training multiple machine learning classifiers
• Comparing classifier performance
• Explaining model predictions using Explainable AI
• Producing publication-quality figures and tables

---

# Research Motivation

Surface electromyography (sEMG) measures electrical activity generated by skeletal muscles.

Modern prosthetic hands use sEMG signals to recognize the user's intended movement.

Accurate gesture recognition can significantly improve:

- prosthetic control
- rehabilitation
- assistive robotics
- human-computer interaction
- exoskeleton control

Machine learning enables automatic recognition of muscle activation patterns associated with different gestures.

---

# Research Goals

This project aims to answer:

1. Which machine learning classifier performs best on public sEMG datasets?

2. Which EMG features contribute most toward gesture recognition?

3. Can classical machine learning achieve competitive performance without deep learning?

4. Which feature extraction techniques are most informative?

5. Can Explainable AI improve interpretation of gesture classification?
