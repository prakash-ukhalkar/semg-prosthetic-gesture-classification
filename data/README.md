# Data Directory

This directory stores raw, preprocessed, and feature-extracted dataset files for sEMG prosthetic gesture classification.

## Structure
- `raw/`: Raw downloaded NinaPro dataset files (.mat / .npy). (Git ignored)
- `interim/`: Intermediate processed signals and windowed arrays. (Git ignored)
- `processed/`: Cleaned, filtered, and windowed datasets. (Git ignored)
- `features/`: Extracted feature matrices (.parquet / .h5). (Git ignored)
