# Models Directory

This directory contains trained classifier weights, checkpoints, fitted scalers, and Optuna hyperparameter optimization artifacts.

## Structure
- `baseline/`: Trained baseline classifiers (SVM, RF, XGBoost, LightGBM, CatBoost). (Git ignored)
- `optimized/`: Optuna-tuned final model checkpoints and ONNX exports. (Git ignored)
- `scalers/`: Fitted StandardScaler and MinMax scalers. (Git ignored)
