# Outputs Directory

This directory stores generated publication deliverables, figures, evaluation tables, and experiment logs.

## Structure
- `sample_figures/`: Representative high-resolution figures for sample visualization.
- `sample_tables/`: Representative latex/csv tables for benchmark reporting.
- `figures/`: Generated figures and plots. (Git ignored)
- `tables/`: Generated evaluation metric tables. (Git ignored)
- `reports/`: Benchmarking diagnostic reports and logs. (Git ignored)
