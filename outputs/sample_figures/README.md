# Sample Figures

This directory contains a small set of representative, real (non-fabricated) publication figures from the full pipeline, provided so the repository is inspectable without needing to regenerate the entire `outputs/` tree.

- `figure_01_pipeline_overview.png` — end-to-end 15-notebook pipeline diagram (Notebooks 01-15).
- `figure_11_05_heldout_vs_loso_comparison.png` — held-out test vs. 40-fold LOSO validation comparison (real, Notebook 11).
- `figure_12_01_global_shap_summary.png` — global SHAP feature attribution summary (real, CatBoost-native SHAP, Notebook 12).

The full figure set is regenerated by re-running the corresponding notebooks against the processed data (see `REPRODUCIBILITY.md`).
