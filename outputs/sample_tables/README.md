# Sample Tables

This directory contains a small set of representative, real (non-fabricated) evaluation tables from the full pipeline, provided so the repository is inspectable without needing to regenerate the entire `outputs/` tree.

- `overall_results.csv` — held-out test performance (Accuracy, Macro F1, MCC, ROC-AUC, ECE, etc.) for the three tuned classical models (CatBoost, XGBoost, LightGBM).
- `table_01_metrics_summary.csv` — summary evaluation metrics table as used in the manuscript.

The full table set is regenerated by re-running the corresponding notebooks against the processed data (see `REPRODUCIBILITY.md`).
